# Кастомный компонент оформления заказа для Bitrix

Этот кастомный компонент Bitrix предназначен для обработки процесса оформления заказа на сайте электронной коммерции, построенном на платформе Bitrix. Компонент управляет аутентификацией пользователей, корзиной, вариантами доставки и оплаты, свойствами заказа, применением купонов и интеграцией с Яндекс.Картами для выбора адреса. Он обладает высокой настраиваемостью и интегрируется с модулем продаж Bitrix.

## Возможности

- **Аутентификация пользователей**: Поддержка авторизованных и анонимных пользователей с настраиваемым ID для анонимного оформления.
- **Управление корзиной**: Загрузка и отображение корзины пользователя с расчетом цен и количества товаров.
- **Варианты доставки**: Получение доступных служб доставки с учетом ограничений, позволяя пользователю выбрать предпочтительный вариант.
- **Платежные системы**: Отображение доступных способов оплаты с учетом ограничений, позволяя пользователю выбрать подходящий метод.
- **Свойства заказа**: Поддержка настраиваемых свойств заказа (например, имя, телефон, email, адрес) с валидацией обязательных полей.
- **Система купонов**: Возможность применения и удаления купонов через AJAX-интерфейс с динамическим пересчетом общей суммы заказа.
- **Интеграция с Яндекс.Картами**: Автодополнение адреса и выбор адреса на карте с фиксированным местоположением (Уфа) для оформления заказа.
- **Выбор даты доставки**: Настраиваемый выбор даты доставки с учетом выходных и запрещенных дат.
- **Согласие пользователя**: Поддержка согласий пользователей, как требуется модулем согласий Bitrix.
- **Обработка ошибок**: Отображение ошибок валидации для обязательных полей и системных ошибок при обработке заказа.
- **Поддержка AJAX**: Асинхронная обработка применения и удаления купонов для улучшения пользовательского опыта.
- **Расчет цен**: Отображение форматированных цен на товары, доставку и общую сумму с динамическим обновлением при применении купонов или изменении доставки.

## Файлы

- **`component.php`**: Основная PHP-логика компонента, отвечающая за создание заказа, загрузку корзины, обработку доставки и оплаты, свойств заказа и формы.
- **`template.php`**: Шаблон фронтенда для отображения формы оформления заказа, включая поля свойств, доставку, оплату, купоны и интеграцию с Яндекс.Картами.
- **`ajax_order.php`**: Обработка AJAX-запросов для применения и удаления купонов, а также получения списка активных купонов с пересчетом цен.
- **`js/suggest.js`**: JavaScript-файл для реализации автодополнения адресов с использованием API Яндекс.Карт. Обрабатывает ввод адреса, отображает подсказки и геокодирует выбранный адрес.
- **`js/streets.js`**: JavaScript-файл для локального автодополнения адресов на основе загруженного JSON-файла `streets_optimized.json`. Фильтрует улицы по введенному запросу и обновляет стоимость доставки.
- **`js/delivery.js`**: JavaScript-файл для работы с Яндекс.Картами, отображения зон доставки, расчета стоимости доставки по координатам и управления купонами через AJAX.

## Установка

1. **Размещение файлов компонента**:
    - Скопируйте папку компонента (содержащую `component.php`, `template.php` и дополнительные файлы, такие как `ajax_order.php`) в директорию компонентов Bitrix (например, `/bitrix/components/tega/order.simple/`).
    - Разместите JavaScript-файлы (`suggest.js`, `streets.js`, `delivery.js`) в папке шаблона компонента.
    - Убедитесь, что файл `streets_optimized.json` доступен в корневой директории или укажите правильный путь в `streets.js`.

2. **Настройка параметров компонента**:
   - Установите обязательные параметры в настройках компонента, такие как:
     - `PERSON_TYPE_ID`: ID типа плательщика для заказа.
     - `SITE_ID`: ID сайта для экземпляра Bitrix.
     - `FORM_NAME`, `FORM_ID`, `FORM_ACTION`: Идентификаторы формы и URL действия.
     - `ORDER_PROPS`: Массив ID свойств заказа для отображения.
     - `REQUIRED_ORDER_PROPS`: Массив ID обязательных свойств для валидации.
     - `FIO_PROPERTY`, `PHONE_PROPERTY`, `EMAIL_PROPERTY`, `DATE_PROPERTY`: ID для конкретных свойств (ФИО, телефон, email, дата).
     - `USE_DATE_CALCULATION`, `DATE_FORMAT`, `CLOSING_TIME`, `DATES_INTERVAL`, `PROHIBITED_DATES`, `WEEKEND_DAY_*`: Настройки, связанные с датами для планирования доставки.
     - `USER_CONSENT`, `USER_CONSENT_ID`, `USER_CONSENT_IS_CHECKED`, `USER_CONSENT_IS_LOADED`: Настройки согласий пользователей.
     - `BASKET_PAGE`, `ORDER_RESULT_PAGE`: URL для перенаправления при пустой корзине или успешном заказе.
     - `EVENT_TYPES`: Массив типов событий для email-уведомлений о заказе.
     - `SET_DEFAULT_PROPERTIES_VALUES`: Опция для предзаполнения данных пользователя для авторизованных пользователей.

3. **Настройка Яндекс.Карт**:
    - Убедитесь, что действительный API-ключ Яндекс.Карт указан в теге `<script>` в `template.php` (`<script src="https://api-maps.yandex.ru/2.1/?apikey=[YOUR_API_KEY]"></script>`).
    - Проверьте, что файлы `suggest.js` и `delivery.js` корректно подключаются для автодополнения адресов и работы с картой.

4. **Добавление обработчика AJAX**:
    - Разместите `ajax_order.php` в подходящем месте (например, `/personal/order/make/ajax_order.php`) и убедитесь, что он доступен для AJAX-запросов, связанных с купонами.
    - Убедитесь, что путь `/personal/order/make/ajax_delivery.php` в `delivery.js` соответствует фактическому расположению вашего AJAX-обработчика.
## Использование

1. **Оформление заказа**:
    - Компонент отображает форму с полями для ввода свойств заказа (ФИО, телефон, email, адрес), выбором доставки и оплаты, полем для ввода промокода и интерактивной картой Яндекс для выбора адреса доставки.
    - Пользователи могут ввести адрес вручную с автодополнением (на основе локального файла `streets_optimized.json` или API Яндекс.Карт) или выбрать точку на карте, чтобы автоматически определить адрес и рассчитать стоимость доставки.
    - Доступен выбор даты доставки (если включен параметр `USE_DATE_CALCULATION`), исключая выходные и запрещенные даты, настроенные в параметрах компонента.

2. **Работа с промокодами**:
    - Пользователи могут ввести промокод в поле и нажать «Применить купон», чтобы получить скидку. AJAX-запрос, обработанный `ajax_order.php`, обновляет итоговую сумму заказа и отображает сообщение об успехе или ошибке.
    - Список активных промокодов отображается в контейнере `couponListContainer`, с возможностью удаления каждого промокода, что также вызывает пересчет цен.
    - Все действия с промокодами (применение, удаление, отображение списка) выполняются асинхронно для улучшения пользовательского опыта.

3. **Выбор адреса и расчет доставки**:
    - При вводе адреса в поле `address` отображаются подсказки, основанные на локальном списке улиц (`streets.js`) или API Яндекс.Карт (`suggest.js`).
    - При клике по карте или выборе адреса из подсказок выполняется геокодирование для получения координат, после чего рассчитывается стоимость доставки на основе зон, определенных в `delivery.js` (Центр, Проспект Октября, Дальняя зона).
    - Стоимость доставки отображается в форме и сохраняется в скрытом поле `DELIVERY_CUSTOM_PRICE` для передачи в `component.php` при отправке заказа.

4. **Отправка заказа**:
    - После заполнения формы и нажатия кнопки «Оформить заказ» компонент валидирует обязательные поля и сохраняет заказ в системе Bitrix.
    - При успешном сохранении пользователь перенаправляется на страницу результата (если указан `ORDER_RESULT_PAGE`) или видит сообщение об успешном создании заказа.
    - Если настроены `EVENT_TYPES` и пользователь авторизован, отправляются email-уведомления с информацией о заказе, включая товары, стоимость и контактные данные.

## Зависимости

- **Модули Bitrix**:
    - `sale`: Обязательный модуль для управления заказами, корзиной, доставкой, оплатой и системой скидок.
    - `main`: Требуется для работы с пользователями, локализацией и отправкой почтовых событий.

- **Внешние библиотеки**:
    - **Яндекс.Карты API (версия 2.1)**: Используется для автодополнения адресов, геокодирования и отображения интерактивной карты с зонами доставки (`suggest.js`, `delivery.js`).
    - **Bitrix JavaScript API (BX)**: Применяется для обработки отправки формы и выполнения AJAX-запросов в `template.php`.
    - **JSON-файл `streets_optimized.json`**: Локальный файл с данными об улицах и типах улиц для автодополнения адресов (`streets.js`).

## Настройка

- **Свойства заказа**: Настройте параметр `ORDER_PROPS` в `component.php` для включения или исключения полей формы (например, ФИО, телефон, email, адрес). Укажите `REQUIRED_ORDER_PROPS` для обязательных полей.
- **Зоны доставки**: Отредактируйте массив `deliveryZones` в `delivery.js` для изменения координат, цен и названий зон доставки. Настройте цвета полигонов (`color`) для визуального отображения на карте.
- **Автодополнение адресов**:
    - Обновите путь к `streets_optimized.json` в `streets.js`, если файл находится не в корневой директории.
    - Настройте параметры в `suggest.js`, такие как `boundedBy` для ограничения области поиска адресов или `results` для количества подсказок.
- **Промокоды**: Убедитесь, что модуль скидок Bitrix настроен для поддержки промокодов, и проверьте путь к AJAX-обработчику (`/personal/order/make/ajax_delivery.php`) в `delivery.js`.
- **Стилизация**: Добавьте CSS в шаблон Bitrix для оформления формы, карты, таблицы цен и контейнера подсказок (`suggestions`). Например, настройте стили для `.suggestion-item`, `.success`, `.error` в `template.php`.
- **Ограничения по датам доставки**: Используйте параметры `PROHIBITED_DATES` и `WEEKEND_DAY_*` в `component.php` для исключения определенных дат или дней недели из выбора доставки.
- **Расширение AJAX-логики**: Модифицируйте `ajax_order.php` или `delivery.js` для добавления новых действий, например, динамического обновления стоимости доставки при изменении адреса без перезагрузки страницы.

## Примечания

- Компонент фиксирует местоположение «Уфа» (код местоположения: `0000728734`) в `template.php` для функций, связанных с адресом. Для использования другого города обновите `defaultLocationCode` и настройте координаты в `suggest.js` и `delivery.js`.
- Для работы автодополнения и карты требуется действительный API-ключ Яндекс.Карт. Убедитесь, что он указан в `template.php`, и проверьте подключение `suggest.js` и `delivery.js`.
- Файл `streets_optimized.json` должен быть доступен и содержать корректные данные об улицах (формат: `{ "types": {}, "streets": [[type, name], ...] }`). Если файл отсутствует, автодополнение в `streets.js` не будет работать.
- Промокоды зависят от настроек модуля скидок Bitrix. Проверьте, что купоны созданы и активны в административной панели, и что `ajax_order.php` корректно обрабатывает запросы.
- AJAX-обработчик в `delivery.js` использует путь `/personal/order/make/ajax_delivery.php`, который должен совпадать с расположением `ajax_order.php` или быть перенаправлен на него через серверные настройки.
- Перед развертыванием в продакшен протестируйте компонент, включая автодополнение адресов, расчет доставки, применение промокодов и отправку заказа, чтобы убедиться в совместимости с вашей конфигурацией Bitrix.
- Если возникают ошибки при геокодировании или расчете доставки, они отображаются в блоке `result` с классом `error`. Для диагностики проверяйте консоль браузера и логи сервера.
